# 研发编审工具（rdreview）

面向制造展演示的研发编审：判断一组相互约束的工艺要素，是否在**同一份可确认
公开记录、同一实施条件下同时出现**；以及观众把展板、讲解、会后资料联合起来
能推出什么。工具只做受控规则分析，**不用字面相似度凑先例，不用相似词补齐
资料里没有记录的关系**——缺证内容一律留待工程员确认。

## 判定原则

1. **要素级语义**：每条原文解析为对象、动作（含先后顺序）、条件、描述强度、
   通用性自称、引用、缺席（“未说明 X”）七类要素，因子用规范化名称比较。
2. **先例必须同记录同条件**：一组要素只有在同一份公开记录（或验签后的同一
   实施方式续页链）里同时出现才算共同公开过。跨装置、跨记录的两条只生成
   “拆分陷阱”，并逐条说明不能援引的原因（闭门、未验签、明确缺记、条件不同）。
3. **引用六分**：同一实施方式续页、备选实施、同场指代、动作委托、图注来源、
   步骤重复。备选实施的要素不与主实施方式并为同一先例。
4. **观众视角联合推断**：按观众实际接触的全部材料（`seen` + `planned`）合并
   因子；只要保密组合的各因子都能找到，且存在串接线索（同场指代、图注、
   同名对象、工件顺序），即视为可推出——**只删一个工艺词但图注/顺序仍在时，
   判定为仍可推出**。
5. **许可四级并从严**：可公开 < 签约可见 < 暂时保密 < 待确认。条件性批准
   （验签后生效）只授予签名链上明确公开过的因子；链上任一页明确缺记的条件
   （如 D4“未说明低压”）始终无公开支持。
6. **通用性越界**：材料自称通用/示范但只给一款实物示例时，标出公开能支持的
   范围，禁止外推。
7. **改法三选且保原理**：可删 / 可换（工程员登记替换表述）/ 只能给另一组
   观众；删除某因子若使依赖它的原理动作失去前提，明确标出“讲不清的部分”，
   排序时优先保留能讲清原理的公开动作。
8. **单发与同发分开判**：两份各自可盖章的草稿，同发后越过许可时整组驳回，
   不能分别盖章。
9. **验签可翻案**：排练后补入带签名公开存档，可重新判断以前缺证的实施方式，
   恢复明确公开过的部分；缺记部分不恢复。
10. **会后事故处置**：展示结束后发现限制扩面，保存当时各批实际所见快照、
    冻结继续分发的问题组合、指出要联系哪批观众。所有动作带序号、时间、
    操作人留痕，可按中文业务词或因子名回查。

## 使用

CPython 3.11、仅标准库。资料包只读；编审状态默认写入 `review_workspace/`
（已在 .gitignore）。

```sh
# 资料包物理格式校验（原有）
python3 pack_check.py

# 端到端故事线演示（状态写临时目录）
python3 -I rdreview/demo.py

# 命令行
python3 -I rdreview/cli.py list                     # 全量记录、分组、批准、批次
python3 -I rdreview/cli.py show D4                 # 单条记录的要素与引用
python3 -I rdreview/cli.py refs                    # 全部跨页/跨载体引用
python3 -I rdreview/cli.py review S1               # 按观众批次评审（含待发组合）
python3 -I rdreview/cli.py review S3 --seen-only   # 只评实际已看部分
python3 -I rdreview/cli.py precedent --proposal P2 # 先例与拆分陷阱
python3 -I rdreview/cli.py generic                 # 通用性越界
python3 -I rdreview/cli.py verify D4 --actor 张工  # 验签签名存档并重新判断
python3 -I rdreview/cli.py clear P2 condition.low_pressure 暂时保密 --actor 李工
python3 -I rdreview/cli.py drop P2 condition.low_pressure  # 模拟删词
python3 -I rdreview/cli.py replace P4 condition.low_pressure condition.standard_pressure 常规压力
python3 -I rdreview/cli.py re-audience P4 签约组
python3 -I rdreview/cli.py incident S1             # 会后扩面事故：快照+冻结+联系批次
python3 -I rdreview/cli.py trace 低压              # 回查全部相关来由
```

## 模块

- `models.py`：要素、引用、记录、批准、批次、结论、事件的数据模型
- `lexicon.py`：受控词库、因子规范名、引用/缺席/顺序模式
- `parser.py`：中文规则解析（不做相似度归并）
- `loader.py`：TSV 装载与批准原话的结构化解析
- `precedent.py`：实施方式分组、共同公开先例、拆分陷阱
- `clearance.py`：要素级许可解析、条件性批准、通用性越界
- `inference.py`：观众视图、联合推断泄密路径、编审改法与前提检查
- `store.py`：状态持久化、事件留痕、快照、冻结、回查
- `project.py`：工作流门面（验签翻案、事故立案）
- `cli.py` / `display.py` / `demo.py`：命令行、输出、端到端演示
